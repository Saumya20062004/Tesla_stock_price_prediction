# Tesla Stock Time Series Analysis

## Project Overview
This project focuses on analyzing and predicting Tesla stock prices using time series forecasting techniques. The primary goal is to predict future stock prices based on historical data to assist in making informed investment decisions.

## Technologies Used
- **Python**
- **Pandas**
- **Matplotlib**
- **Statsmodels**

## Key Highlights
- Developed a time series forecasting project to analyze Tesla stock prices.
- Conducted stationarity checks using the **Augmented Dickey-Fuller (ADF)** test to ensure data suitability for time series modeling.
- Built and fine-tuned an **ARIMA model** for stock price prediction, which achieved improved trend forecasting accuracy.
- Visualized key insights such as closing price trends, moving averages, and forecasted values for strategic analysis.

## Data
The dataset contains historical stock prices of Tesla, including columns like:
- Date
- Open Price
- High Price
- Low Price
- Close Price
- Volume

The data was sourced from a publicly available stock price database and cleaned for the analysis.
